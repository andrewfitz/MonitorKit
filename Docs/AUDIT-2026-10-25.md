Tests exercise invalid requests, retries and stale-state clearing.
- **Resources and compilation:** publish residency retirement counts under the list lock; preserve stencil-only sample counts; retain archive dirty state after partial recording failures; validate cache requests and sanitize invalid clocks; bound warm-up dimensions; make asynchronous scope completion/failure terminal before releasing pending state.
- **Scope output:** preserve the full SIMD ballot when counting packed bins, normalize invalid graticule dimensions, regroup when cadence changes, and separate stopped scopes from hidden scopes that continue measuring. The SIMD regression conserves pixel counts with partial threadgroups; the upper-lane defect specifically requires 64-lane hardware to reproduce.
- **Core math and geometry:** avoid division by zero for equal BT.1886 endpoints; evaluate white-point tangents at the clamped temperature; reject nonfinite computed optional color results; normalize direct layout input and bound guide work/conversions.
- **Audio:** decay peak holds only for frames after their expiry; validate derived calibration and VU/PPM coefficients; bound custom scale mark generation; prevent programme-pair integer overflow and histogram conversion traps; evaluate biquad magnitudes with scaled hypotenuse calculations.
- **UI lifecycle and input:** clear stale surface/scope geometry, validate mutated display configuration, schedule completion release for already-paused offscreen draws, observe UIKit scene activation, reject nonfinite gestures and invalid overlay geometry, safely cache/format large readings, and honor unavailable reasons in list legends.
- **Additional audit coverage without speculative source edits:** LUT parsing and numerical boundaries, CPU/GPU LUT parity, optimized v210 extraction across every partial-group tail, audio snapshot handoff and staged input sanitization.

## Remaining limitations

- Loudness histogram gates and LRA use bins from −70 to +30 LUFS. Values above +30 share the top bin and lose resolution. Extremely large custom Double channel weights can overflow energy calculations and do not yield meaningful loudness readings; conversion guards prevent histogram traps. These are documented in the API and loudness meter comments rather than expanding every meter's histogram allocation substantially.
- A synchronous cold scope-pipeline request from multiple threads may compile the same key more than once before the cache converges. The asynchronous failure/restart race is fixed.
- Hosts remain responsible for truthful, monotonic Metal 4 submission/completion indices, retaining resources until GPU completion, and bounding classic in-flight work. Public mutable submission indices can bypass constructor normalization.
- UIKit lifecycle behavior requires an iOS device run in addition to compilation. The 64-lane SIMD case needs compatible hardware; local conservation tests also run on 32-lane devices.

This audit is a broad review with regression validation, not a proof that all possible defects are absent.
